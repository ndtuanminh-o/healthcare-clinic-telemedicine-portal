# EER Diagrams

The diagrams follow the style reference supplied by the team: entities are
rectangles, attributes are ovals, relationships are diamonds, primary keys are
underlined, derived attributes use dashed ovals, and specialization uses an
`is a` relationship.

## Official Diagram

- `er_diagram.drawio`: the refined EER diagram selected for the Phase 1
  submission. It contains one overview page and detailed component pages.

Open either `.drawio` file with diagrams.net or the Draw.io desktop application.
